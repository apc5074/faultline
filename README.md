# Faultline

Faultline is a daily distributed-systems design game.

## Development

Install dependencies from the repository root:

```sh
pnpm install
```

Run the local application at `http://localhost:3000`:

```sh
pnpm dev
```

Run the available checks:

```sh
pnpm typecheck
pnpm build
```

The application currently provides the Phase 0 production shell. See `plans/phase 0/plan.md` for the active implementation sequence.
